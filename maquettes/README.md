# Maquettes d'origine (archives)

Pages statiques fournies au démarrage du projet, conservées pour référence. **Elles ne sont pas servies par le site.**

Le site réel est dans `public/` :

| Maquette | Remplacée par |
| --- | --- |
| `index.html` | `public/index.html` (boutique, même design, photos reprises dans `public/assets/img/`) |
| `fiche-produit.html` | `public/produit.html` (`/produit/fer`, `/produit/vit`, `/produit/pro`) |
| `espace-revendeur.html` | `public/revendeur.html` (`/revendeur`) |

⚠️ `espace-revendeur.html` affiche d'anciennes remises (−40/−50/−55 %) et « 20 % niveau 1 ». La grille en vigueur est dans la configuration (admin) : packs −30/−40/−50 %, ventes clients 20 % vendeur / 10 % / 5 %.
